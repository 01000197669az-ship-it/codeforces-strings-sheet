# Codeforces Strings Sheet (C++)

Solutions from the Sheet 5 String group on Codeforces, written in C++ while learning `std::string`. All of these are marked Accepted on Codeforces.

| File | Problem |
|------|---------|
| `E_count.cpp` | E - Count |
| `F_way_too_long_words.cpp` | F - Way Too Long Words |
| `G_conversion.cpp` | G - Conversion |
| `H_good_or_bad.cpp` | H - Good or Bad |
| `I_palindrome.cpp` | I - Palindrome |
| `J_count_letters.cpp` | J - Count Letters |
| `K_i_love_strings.cpp` | K - I Love strings |

Compile and run:

```
g++ -o sol E_count.cpp
./sol
```
